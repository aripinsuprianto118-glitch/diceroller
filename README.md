Dice Roller App Android

Deskripsi

Aplikasi Android sederhana yang dibuat menggunakan Jetpack Compose untuk menyimulasikan lemparan dadu. Aplikasi ini interaktif dan menampilkan gambar dadu yang berubah secara acak (dari angka 1 hingga 6) setiap kali pengguna menekan tombol.

Fitur

Menyimulasikan lemparan dadu secara acak.

Menggunakan Jetpack Compose.

Menggunakan State (remember dan mutableStateOf) untuk memperbarui UI secara dinamis.

Menggunakan komponen Button dan Image.

Menggunakan resource string dan gambar (gambar wajah dadu 1-6).

Teknologi

Kotlin

Android Studio

Jetpack Compose
